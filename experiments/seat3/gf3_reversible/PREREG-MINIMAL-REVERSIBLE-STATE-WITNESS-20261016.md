## Hypothesis — exact minimal reversible lift, not extra photons or independent physical memory

Original GF(3) transition `(T x)[i]=x[i]+x[(i-a)%81]+x[(i-b)%81] (mod3)`, for laws (a,b)=(1,3) and (4,7), as tested in parent. Both have `rank(T^h)=81-min(h,81)` and `T^81=0`. A single visible output state cannot reconstruct arbitrary initial input. For each step, retain **one trit** `w_t = x_t[0]` before applying T: the map `x -> (Tx,x[0])` is injective because `ker T = {constant vectors}` and a constant nonzero kernel vector has nonzero coordinate 0. For h<=81, exactly h witness trits suffice to invert and distinguish all possible input states for a known law schedule; no fewer than h trits suffice because the kernel has dimension h for the declared fixed laws. (For an arbitrary law-switch schedule, establish rank separately before claiming minimality.) At h81, 81 trits are necessary, capacity `81*log2(3)` ≈ 128.4 bits, at least 17 bytes; 5 trits/byte encodes them in 17 bytes plus **separate** format header and source metadata. No claim this compression increases independent memory capacity.

Test laws 013 and 047; horizons 1,3,9,27,81, and a 17× law013 then 23× law047 composite (40 logical steps). Include at least five deterministic initial 81-trit states: e0, e13, e80, dense `(7i+2)%3`, alternating `i%3`. At each step record x[0], perform actual transition. Verify direct forward recurrence and reconstruct all 81 initial trits **backwards**, including same final zero after h81, with exact source-bound original identity. At fixed h the expected minimum sideband trits are h, and power-map rank is 81-h for h<=81. For switched 17+23 law, independently test its kernel rank/nullity rather than assume. Inject witness flip: absent an independently trusted initial state/hash, modified witness yields a different mathematically valid predecessor, so a *self-owned hash cannot certify original provenance*. Under a **pinned original initial state**, altered witness must fail source reconstruction.
