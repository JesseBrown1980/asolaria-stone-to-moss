## Fixed idealized photon/electron law

On/off keying (OOK) of source bit b: `N_emit = N * b` per independent replica; no light is emitted for b=0. At storage tick t, each emitted photon independently results in a detected *modeled photoelectron* with probability
`p_detect = (4/5) transport × (4/5)^t retention × (4/5) quantum efficiency = (4/5)^(t+2)`.

For N photons, `photoelectrons ~ Binomial(N, p_detect)`; for zero bit, there are no signal-generated photoelectrons. Add a modeled dark electron (0 or 1) with independently sampled Bernoulli probability d. The digital electronic threshold is `photoelectrons + dark_electrons > 0`. Five-replica majority vote is applied per bit in the protected regime.

These are **declared assumed** loss/detector parameters (not fitted to observations). Reproduce finite-count random samples **deterministically** across Python and Node via SHA256-seeded xorshift32 and exact integer binomial inverse CDF with 32-bit probabilities (round-down). Cross-language byte-identical results are required. Expected single-window error for source 1 is `(1-p_detect)^N × (1-d)`; for source 0 it is `d`. Evaluate those analytical expectations against observed finite-grid BER, without pretending the deterministic pseudo-draw is measured quantum randomness.

Five frozen scenarios:
1. `bright_t0`: N=24, t=0, d=0, replicas=1.
2. `dim_t0`: N=1, t=0, d=0, replicas=1.
3. `bright_t3`: N=24, t=3, d=0, replicas=1.
4. `dark_t0`: N=24, t=0, d=1/1000, replicas=1.
5. `protected_t3`: N=24, t=3, d=1/1000, replicas=5.

Model wavelengths in nm: red 650, orange 610, yellow 580, green 530, blue 470, indigo 440, violet 405. They are **hypothetical input labels**, NOT seven physically calibrated sources. Photon energy is computed per wavelength as `hc/λ` using exact SI definitions, with round-to-nearest integer yoctojoules per photon for portable accounting. Electron charge is the SI elementary charge per modeled primary photoelectron, not a physical measured current. These physical constants do not convert computer variables into actual photons.
